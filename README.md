# Мини-CRM

Учебная CRM для учёта клиентов. Работает локально в браузере, без сторонних зависимостей.

Текущий этап: добавление клиента (имя и телефон обязательны), список клиентов, сохранение в `localStorage`,
статус клиента («Новый», «В работе», «Завершён») и фильтр списка по статусу,
редактирование имени и телефона, удаление клиента с подтверждением,
поиск по имени или телефону и сортировка списка (по дате создания или по имени).

Телефон должен быть уникальным: при сравнении не учитываются пробелы, скобки, дефисы и знак `+`,
а сохраняется и показывается номер в том виде, как его ввели.

## Требования

- Node.js 24 или новее

## Запуск

```bash
node server.js
```

Откройте в браузере http://127.0.0.1:3000. Остановить сервер: `Ctrl+C`.

Другой порт: задайте переменную окружения `PORT`.

> Файл `index.html` нельзя просто открыть двойным щелчком: браузеры не загружают JavaScript-модули с диска (`file://`). Поэтому нужен маленький локальный сервер `server.js`.

## Тесты

```bash
node --test
```

## Где хранятся данные

Клиенты сохраняются в `localStorage` браузера под ключом `client-crm.clients`.
Данные привязаны к браузеру и адресу `http://127.0.0.1:3000`: в другом браузере
или по адресу `localhost:3000` список будет пустым. Очистка данных сайта в браузере удалит клиентов.

Статус хранится в поле `status` кодом: `new`, `in_progress` или `done`. Клиенты без статуса
(созданные до его появления) считаются новыми. Выбранный фильтр списка хранится под ключом
`client-crm.status-filter`, выбранная сортировка — под ключом `client-crm.sort`.
Строка поиска после перезагрузки не сохраняется.

## Структура

```
index.html          — страница
styles.css          — оформление
server.js           — локальный сервер для разработки
src/app.js          — форма и список на странице
src/clients.js      — проверка и создание клиента
src/storage.js      — сохранение и загрузка из localStorage
test/               — тесты (node --test)
```
